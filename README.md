# Kingdom

Khung ban đầu cho visual novel Ren'Py + Python về quản lý vương quốc.

## Chạy thử

1. Mở Ren'Py Launcher.
2. Chọn `Preferences > Projects Directory`, trỏ tới thư mục cha của project này.
3. Chọn project `Kingdom`.
4. Bấm `Launch Project`.

## Build EXE

Máy hiện tại chưa có lệnh `renpy` trong PATH, nên chưa build được file `.exe` trực tiếp từ terminal.

Khi đã cài Ren'Py SDK:

1. Mở Ren'Py Launcher.
2. Chọn `Kingdom`.
3. Chọn `Build Distributions`.
4. Chọn bản `Windows`.
5. Build xong, file `.exe` sẽ nằm trong thư mục phân phối mà Ren'Py tạo ra.

Tên game, tên thư mục build, và tên executable đã đặt là `Kingdom`.
